# TermVista

**リモート作業を、ひとつのワークスペースに。** TermVista は macOS と Windows 向けのデスクトップ SSH ワークスペースです。ターミナル、SFTP ファイル管理、サーバー監視、リモートファイル編集、ユーザーが許可した AI 支援機能をまとめて利用できます。

**現在のアプリバージョン：0.10.24**

[公式サイト](https://auyang.github.io/TermVista/) · [English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md)

## 0.10.24 の新機能

- **4 言語のインターフェース：**English、简体中文、日本語、繁體中文に対応し、システム言語にも追従できます。切り替えはすぐに反映されます。
- **AI Copilot 2.0：**ローカルの Ollama モデルまたは OpenAI 互換 API を利用できます。ユーザーが許可した場合に限り、選択したターミナル、エディター、SFTP、監視データを使った説明や、根拠を引用する診断を行います。Shell コマンド案や Monaco のコード差分も作成できます。コマンドは確認用にコマンドバーへ挿入されるだけで、自動実行されません。コード案はローカルの編集バッファーに留まり、適用と保存はユーザーが行います。
- **署名付きアプリ内更新：**「TermVista について」から更新を確認でき、起動時の確認も選択できます。リリースノートと実際のダウンロード進捗を表示し、署名検証に成功した更新パッケージだけを受け入れます。未保存の編集、転送、診断、AI リクエストなどの作業中はインストールを待機します。SSH セッションやトンネルが動作中の場合は、中断前に確認を求めます。
- **作業へのスムーズな復帰：**接続プロファイルを検索し、お気に入りや最近の接続を利用できます。再起動後はローカルのサーバータブ、パネル配置、サーバーごとの前回の SFTP パスを復元できます。タブの自動再接続は任意で、通常のホスト鍵検証と認証を行います。リモートの Shell やプロセスは復元しません。

## ワークスペース機能

- **SSH ターミナル：**パスワード認証と秘密鍵認証、分離された複数セッションタブ、対話型 PTY、再接続操作、アクティブな PTY と共有するコマンドバーに対応。
- **SFTP ファイル管理：**リモートのディレクトリツリーとファイル一覧を表示し、ローカル／リモートの 2 ペイン表示に切り替えられます。ドラッグ＆ドロップ転送、進捗表示、キャンセル、再試行、競合時の選択に対応。
- **リモートファイル編集：**Monaco Editor でリモートのテキストファイルを開き、サーバーやファイルごとのタブ、構文ハイライト、未保存変更の表示、保存前の競合確認ができます。
- **サーバー監視とポートフォワーディング：**リモートの CPU、メモリ、プロセス、ネットワーク、ディスク情報を表示します。MySQL、PostgreSQL、Redis、または任意の TCP サービス向けに SSH ローカルフォワーディングを設定できます。リスナーは 127.0.0.1 にバインドされ、SSH セッションの切断またはアプリ終了時に停止します。
- **ワークスペース表示：**ライト／ダークテーマを切り替え、監視、ターミナル、エディター、SFTP のレイアウトを調整できます。

## セキュリティとプライバシー

- 初回接続時にユーザーが確認した SSH ホストフィンガープリントをローカルに保存します。次回以降に変更を検出すると接続をブロックし、確認を求めます。
- SSH パスワードと秘密鍵のパスフレーズはローカルの安全な認証情報ストレージに保存できます。平文での保存にはフォールバックしません。
- AI が SSH コマンドを実行したり、リモートファイルを書き換えたりすることはありません。共有前にユーザーがコンテキストを選択して確認し、診断にも個別の許可が必要です。生成されたコマンドはユーザーが確認して実行し、コード案の適用と保存もユーザーが行います。
- 接続プロファイル、信頼済みホスト記録、保存した認証情報はローカルに保存され、ソースリポジトリやアプリパッケージには含まれません。
- ローカルポートフォワーディングは 127.0.0.1 のみで待ち受けます。同じコンピューター上の他のプロセスから転送先サービスへ接続できるため、開始前に接続先を確認してください。

| --- | --- |

Linux 用インストーラーは現在提供していません。Windows インストーラーにはコード署名がありません。macOS パッケージは ad-hoc 署名で、公証も行っていないため、初回起動時に OS の警告が表示される場合があります。

## クイックスタート

1. 使用するプラットフォーム向けの TermVista をダウンロードしてインストールします。
2. SSH サーバーのプロファイルを追加し、ホスト、ポート、ユーザー名、認証方式を入力します。
3. 初回接続時は、表示されたホスト鍵のフィンガープリントを信頼できる情報源と照合してから信頼するか決めてください。ログイン認証情報をローカルに保存するかどうかは選択できます。
4. 接続タブでターミナルと SFTP を利用します。リモートのテキストファイルをダブルクリックするとエディターで開きます。
5. AI Copilot を使う場合は Ollama または OpenAI 互換プロバイダーを設定し、共有するコンテキストを選んで認可プレビューを確認します。

## ソースから実行

開発環境には Node.js 22、pnpm 10.32.1、Rust stable、および Tauri 2 のプラットフォーム別ビルド依存関係が必要です。

    pnpm install --frozen-lockfile
    pnpm tauri dev

フロントエンドだけをプレビューする場合は pnpm dev を実行します。このモードでは SSH 接続を確立せず、実在しないサーバー監視データも表示しません。
